# Paint App (C83)

A browser drawing app on an HTML canvas. Supports touch drawing with a selectable colour and line width, and resizes the canvas for smaller screens.

**Live page:** https://saathvik-the05.github.io/classwork-c83-paint-app/ (touch input; open on a phone or tablet)

**Built with:** HTML, CSS, JavaScript (Canvas API)

> Classwork from an external online coding course (2021). I wrote most of the HTML, CSS and JavaScript myself.
